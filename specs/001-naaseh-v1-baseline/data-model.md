# Data Model: Na'aseh v1 Baseline

## Modeling Rules

- All identifiers are ULIDs generated by the creating client or service and validated server-side.
- All timestamps are UTC RFC 3339 strings; due dates also retain the originating IANA time zone.
- Every mutable entity has an integer `version` incremented by the server.
- Every mutation has a globally unique `mutationId` scoped to its authenticated user/device.
- Hidden memo plaintext, passwords, PINs, raw sessions, and plaintext keys are never stored.
- DynamoDB transactions atomically write current state, immutable revision, idempotency result,
  and authorized sync-feed change after a feed sequence has been allocated.
- Deactivation uses status fields and tombstones; historical attribution is not physically deleted.

## Domain Entities

### User

| Field                 | Type       | Rules                                                         |
| --------------------- | ---------- | ------------------------------------------------------------- |
| userId                | ULID       | Immutable primary identifier                                  |
| username              | string     | Display value; 1–64 Unicode characters                        |
| usernameCanonical     | string     | Trimmed and Unicode case-folded; globally unique              |
| passwordVerifier      | PHC string | Argon2id parameters, salt, hash, and pepper version reference |
| pictureKey            | string     | Optional private S3 object key; never a public URL            |
| pinWrapMetadata       | object     | Salt, Argon2id parameters, algorithm and version; no PIN      |
| role                  | enum       | `user` or `admin`                                             |
| status                | enum       | `active`, `disabled`                                          |
| sessionEpoch          | integer    | Increment to revoke all sessions/offline leases               |
| createdAt / updatedAt | timestamp  | Server controlled                                             |
| version               | integer    | Optimistic concurrency                                        |

**Transitions**: `active -> disabled`; reactivation requires an explicit admin operation.
Disabling increments `sessionEpoch`, revokes sessions, and emits feed tombstones for cached
authorization state without removing historical task/revision actor references.

#### Application Role Permissions

| Capability                                   | `user` | `admin` | Additional boundary                                      |
| -------------------------------------------- | ------ | ------- | -------------------------------------------------------- |
| Read active/referenced categories            | Yes    | Yes     | Required for ordinary task display and editing           |
| Create, update, or archive categories        | No     | Yes     | Server-side role check and immutable audit event         |
| List administrative user views               | No     | Yes     | Never returns password/PIN verifiers or session material |
| Add users and select `user`/`admin` role     | No     | Yes     | Shared provisioning service; secrets are write-only      |
| Disable or reactivate another user           | No     | Yes     | Revokes sessions by incrementing `sessionEpoch`          |
| Disable self or remove the last active admin | No     | No      | Rejected to prevent administrative lockout               |
| View/mutate another user's private task/memo | No     | No      | Ownership and hidden-memo rules are unchanged            |
| Administer a group solely due to app role    | No     | No      | Group owner/manager membership remains authoritative     |

IAM authorization for `scripts/create_user.py` is an operator boundary separate from the
stored application role. It permits invoking only the provisioning function and does not
grant general table, secret, or application-data access.

### Category

| Field                 | Type      | Rules                                                                   |
| --------------------- | --------- | ----------------------------------------------------------------------- |
| categoryId            | ULID      | Immutable                                                               |
| name                  | string    | Trimmed, 1–80 characters, canonical name unique among active categories |
| defaultAssigneeId     | ULID      | Optional active user                                                    |
| color                 | string    | Six-digit sRGB hex; UI must choose accessible foreground                |
| status                | enum      | `active`, `archived`                                                    |
| createdBy / updatedBy | ULID      | Admin users                                                             |
| createdAt / updatedAt | timestamp | Server controlled                                                       |
| version               | integer   | Optimistic concurrency                                                  |

Archived categories remain on existing tasks but cannot be selected for new tasks.

### Group

| Field                 | Type       | Rules                                                         |
| --------------------- | ---------- | ------------------------------------------------------------- |
| groupId               | ULID       | Immutable                                                     |
| name                  | string     | Trimmed, 1–100 characters                                     |
| createdBy             | ULID       | Active user                                                   |
| joinPinVerifier       | PHC string | Optional Argon2id verifier with unique salt; no plaintext PIN |
| status                | enum       | `active`, `archived`                                          |
| createdAt / updatedAt | timestamp  | Server controlled                                             |
| version               | integer    | Optimistic concurrency                                        |

Group membership controls participation and group-targeted behavior. It never hides a
non-private task and never grants access to another owner's private task.
All active users may discover active groups and choose to self-join. V1 has no targeted
invitation records: an explicit join is acceptance, and a configured join PIN is verified
before membership becomes active.

### GroupMembership

| Field                | Type      | Rules                                                           |
| -------------------- | --------- | --------------------------------------------------------------- |
| groupId / userId     | ULID      | Composite identity                                              |
| role                 | enum      | `owner`, `manager`, or `member`; exactly one immutable v1 owner |
| state                | enum      | `active`, `revoked`                                             |
| joinedAt / revokedAt | timestamp | Server controlled; records acceptance and revocation            |
| joinedBy             | ULID      | The self-joining user in v1                                     |
| version              | integer   | Optimistic concurrency                                          |

An active membership join is idempotent. Revocation is terminal in v1: a revoked user
cannot self-reactivate, and restoration requires a future administrator workflow. Owners may
promote or demote active non-owner memberships between `manager` and `member`; ownership
transfer and owner revocation are not supported in v1.

### Task

| Field                     | Type             | Rules                                                                             |
| ------------------------- | ---------------- | --------------------------------------------------------------------------------- |
| taskId                    | ULID             | Immutable                                                                         |
| ownerId                   | ULID             | Immutable active user at creation; retained if disabled                           |
| parentTaskId              | ULID             | Optional; must not create a cycle                                                 |
| label                     | string           | Required, trimmed, 1–300 characters                                               |
| link                      | URL              | Optional HTTPS URL; other schemes rejected                                        |
| memoPlaintext             | string           | Present only when `memoHidden=false`; max 20,000 characters                       |
| hiddenMemoPackage         | object           | Present only when `memoHidden=true`; see cryptographic contract                   |
| memoHidden                | boolean          | Controls storage representation and PIN gate                                      |
| dateAdded                 | timestamp        | Server-set creation time                                                          |
| dueAt                     | timestamp        | Optional UTC instant                                                              |
| dueTimeZone               | IANA zone        | Required with `dueAt`                                                             |
| assigneeId                | ULID             | Optional active user                                                              |
| categoryId                | ULID             | Optional active/archived category reference                                       |
| groupId                   | ULID             | Optional organizational association; not an access or mutation-authority boundary |
| privacy                   | enum             | `public` or `private`; private means owner-only                                   |
| status                    | enum             | `open`, `completed`, `archived`                                                   |
| completedAt / completedBy | timestamp / ULID | Required only when completed                                                      |
| createdAt / updatedAt     | timestamp        | Server controlled                                                                 |
| version                   | integer          | Incremented for every accepted mutation                                           |

**Transitions**:

- `open <-> completed`; repeated completion with the same mutation is idempotent.
- `open|completed -> archived`; restore from archive is a separately audited mutation.
- `public -> private` emits a public tombstone and private-owner upsert.
- `private -> public` emits a private-owner tombstone and public upsert.
- Changing `memoHidden` rewrites memo representation and key packages; plaintext and hidden
  ciphertext are mutually exclusive.

### SyncChange

| Field                 | Type          | Rules                                                   |
| --------------------- | ------------- | ------------------------------------------------------- |
| feed                  | string        | `PUBLIC` or `OWNER#{userId}`                            |
| shard                 | integer       | 0–15 for public; owner feeds may use shard 0 initially  |
| sequence              | integer       | Monotonic within feed/shard; gaps allowed               |
| entityType / entityId | string / ULID | Changed record                                          |
| changeType            | enum          | `upsert`, `tombstone`                                   |
| entityVersion         | integer       | Server version                                          |
| safePayload           | object        | Authorized current representation or redacted tombstone |
| occurredAt            | timestamp     | Server acceptance time                                  |

The client cursor is a vector of `(feed, shard, sequence)` values. It advances only after
the corresponding change batch commits to IndexedDB.

Push payloads contain opaque reminder/task IDs and generic copy, never private labels or memos.

### PushSubscription

Stores user, client installation, endpoint, encrypted Web Push key material, browser/home-
screen capability, created/last-success timestamps, expiration, and status. Endpoint and
keys are encrypted at rest and excluded from ordinary logs.

### HiddenMemoPackage

See [contracts/cryptography.md](./contracts/cryptography.md). The package contains memo
ciphertext, AES-GCM IV/AAD schema, PIN-wrap salt and Argon2id parameters, PIN-wrapped DEK,
single-Region KMS recovery wrap, and key/version identifiers.

## DynamoDB Physical Design

One regional application table in `us-west-2` uses `PK` and `SK`, plus sparse GSIs.
Representative items:

| Item                | PK                                | SK                                 |
| ------------------- | --------------------------------- | ---------------------------------- |
| User                | `USER#{id}`                       | `PROFILE`                          |
| Username claim      | `USERNAME#{canonical}`            | `CLAIM`                            |
| Session             | `SESSION#{digest}`                | `SESSION`                          |
| Category            | `CATEGORY#{id}`                   | `CURRENT`                          |
| Group               | `GROUP#{id}`                      | `CURRENT`                          |
| Membership by group | `GROUP#{id}`                      | `MEMBER#{userId}`                  |
| Membership by user  | `USER#{userId}`                   | `GROUP#{groupId}`                  |
| Task current        | `TASK#{id}`                       | `CURRENT`                          |
| Task revision       | `TASK#{id}`                       | `REV#{versionPadded}#{revisionId}` |
| Idempotency result  | `USER#{userId}#CLIENT#{clientId}` | `MUTATION#{mutationId}`            |
| Feed counter        | `FEED#{audience}#{shard}`         | `COUNTER`                          |
| Feed change         | `FEED#{audience}#{shard}`         | `CHANGE#{sequencePadded}`          |
| Backup manifest     | `BACKUP#{manifestId}`             | `MANIFEST`                         |

Sparse indexes:

- **GSI1 visibility/update**: `PUBLIC#{bucket}` or `OWNER#{ownerId}` + updated/task key.
- **GSI2 due date**: audience/assignee bucket + due time/task key.
- **GSI3 category**: category ID + updated/task key.
- **GSI4 assignee**: assignee ID + updated/task key.
- **GSI5 entity administration**: entity type/status + canonical name/ID.

Conditional writes reserve canonical usernames/category names. Mutations allocate a feed
sequence, then transact current task, revision, idempotency result, and change item. A failed
transaction can leave a sequence gap but cannot leave partial domain state.

## Browser IndexedDB Design

Stores: `users`, `groups`, `memberships`, `categories`, `tasks`, `revisions`, `reminders`,
`cryptoPackages`, `outbox`, `conflicts`, `syncCursors`, `pushSubscriptions`, and `meta`.

- Domain payloads are AES-GCM encrypted with a non-extractable device key stored as a
  structured-clone `CryptoKey`; indexes contain only non-sensitive lookup fields.
- A local entity change and outbox insert occur in one Dexie transaction.
- MiniSearch is derived in memory from decrypted authorized records and is rebuilt after
  schema migration. Hidden memo terms enter only the unlocked in-memory index.
- Logout, session-epoch mismatch, or user disablement clears the database and device key.
- Quota/persistence failures block a false “saved” acknowledgement and preserve actionable state.
